# Kobo-FOMO
I have an old Kobo Glo e-reader from 2010? sometime around then.  I have Irlan disorder which makes reading challenging because it is hard for my eyes to track what they need to make out the words.  A lot of shifting and merging going on.  To assist with this, I rely on bionic lettering.  What is that?

"Renato Casutt created the Bionic Reading Method, which uses an algorithm to strategically bold the first few letters of words (fixation points) to guide the eyes and allow the brain to process words faster." - https://bionic-reading.com/br-method/

The problem:  I can't get e-books, e-readers, Libby, EPUBs, or other digital print formats like PDFs easily or affordably into bionic lettering format.  And access to technology that would enable me to be able have a reliable way to covert what I want to read into bionic lettering also not accessible or affordable.  Perhaps I just didn't look hard enough.  It seems I've been trying since 2016 when I first saw an example of it.  

Regardless, this project is taking my old e-reader and stripping the bloat, keeping the firmware and KRAKEN operating system.  I'm creating a local SNAP tool in Ubuntu called KRAKEN that converts my library into bionic lettering and has push, pull sync with the e-reader.  no wifi connect or store or calendar etc.  I have a custom graphic on sleep and that's it.  I can choose fonts in KRAKEN tool and they sync to reader.  I choose bionic lettering to bold-start and I'm set.  The book all open on the e-reader in the bionic lettering and it also goes for DOCX, ODT, EPUB formats.  

Vibe coded with Claude Code Pro - in terminal.  No subscription fees.  No bloat.  No overreach.  No restrictive access to my library.  Assistive Lettering to help ADHD and Irlan Disorder.  Thank you.
